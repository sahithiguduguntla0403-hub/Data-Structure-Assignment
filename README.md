# Q1: Reverse a String using Stack
This program uses a stack to reverse a given string.
Example:

Input: DATA  
Output: ATAD
# Q2: Balanced Parentheses
This program checks whether the parentheses in an expression are balanced using a stack.
Example:

Input: (A+B)*(C-D)  
Output: Balanced Expression
# Q3: Next Greater Element
This program finds the next greater element for each element in an array using a stack.
Example:

Input: 4 5 2 10 8  

Output:
4 → 5  
5 → 10  
2 → 10  
10 → -1  
8 → -1
# Q4: Printer Queue Simulation
This program simulates a printer queue using basic queue operations.
Operations Supported:
Add document to queue
Print document
Display pending documents
# Q5: Circular Queue (Array Implementation)
This program implements a circular queue using an array.
Operations Supported:
Enqueue (Insert element)
Dequeue (Remove element)
Peek (View front element)
Display (Show all elements)
✔ Menu-driven program for user interaction.
